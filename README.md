One letter, A, for coffee. The first cup of the day, black, before anything else gets done.

The program writes exactly that one letter to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), with nothing else in the file.

## Try it

```sh
python3 main.py
```
